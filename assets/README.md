# assets

Drop the project screenshot here as **`screenshot.png`**. The README references
it at `assets/screenshot.png`, so once you add the file it will show up at the
top of the README on GitHub.

Suggested: a PNG of the main chat window at roughly 1280×800. Make sure the
screenshot contains **no API keys, personal file paths, or private conversation
content** before committing.

`.gitkeep` exists only so this empty folder is tracked by git; you can delete it
once `screenshot.png` is added.
